# YASShoter

Мгновенный скриншотер для Windows на Go: **PrintScreen → выделение области или окна → стрелка/рамка/эллипс/карандаш → Enter → PNG в папку**.

Замена ShareX в той части, которая нужна 95% времени, но без его веса: один нативный `.exe` ~2.5 МБ, без .NET, без CGO, без зависимостей. Резидентный процесс (трей + автозапуск) держит ~15 МБ приватной памяти и 0% CPU, а весь цикл «нажал PrintScreen → появилась подсветка» укладывается в ~0.1 с.

---

## Зачем

ShareX умеет всё, и именно поэтому он долго стартует, долго открывает оверлей и долго поднимает редактор. Здесь оставлен только сквозной сценарий, ради которого скриншотер и нужен:

```text
PrintScreen
   ↓  кадр замораживается (весь рабочий стол затемняется)
выделение мышью  либо  подсветка окна под курсором (клик по окну = снимок окна)
   ↓  отпустил кнопку
редактор прямо на месте выделения (1:1, без окон и панелей поверх картинки)
   ↓  Enter / Ctrl+S
PNG в D:\Downloads + копия в буфер обмена
```

## Возможности

| Что | Как |
| --- | --- |
| Захват области | зажать ЛКМ и растянуть рамку, `Esc` — отмена |
| Захват окна | просто навести на окно и кликнуть (подсветка = границы окна, DWM-рамки, без теней) |
| Стрелка | самый нужный инструмент, включён по умолчанию, красная и толстая |
| Прямоугольник / эллипс | контур той же толщины и цвета |
| Карандаш | свободная линия от руки |
| Метки 1, 2, 3… | нумерованные кружки для инструкций и баг-репортов |
| Толщина | 2 / 4 / 6 / 9 px (клавиши `+` / `-`) |
| Цвет | красный по умолчанию + оранжевый, жёлтый, зелёный, синий, белый, чёрный |
| Undo | `Ctrl+Z` или `Backspace` |
| Сохранить | `Enter` или `Ctrl+S` |
| Скопировать без сохранения | `Ctrl+C` |
| Отмена | `Esc`, `ПКМ` |

Снимок сохраняется в папку из конфига (по умолчанию — системная папка Downloads) и одновременно кладётся в буфер обмена в трёх форматах: `PNG`, `CF_DIB`, `CF_DIBV5` — вставляется и в Telegram, и в Word, и в Paint.

## Почему быстро

* **Нативный Win32 через syscall.** Никакого CGO, рантайма .NET, Avalonia или Skia. Бинарник — 2.5 МБ, старт процесса ~40 мс.
* **Низкоуровневый keyboard hook вместо `RegisterHotKey`.** На Windows 11 PrintScreen принадлежит оболочке (Snipping Tool), и `RegisterHotKey` возвращает ошибку `1409`. Хук получает клавишу раньше системного обработчика и «съедает» её.
* **Захват экрана — один `BitBlt`** с DC рабочего стола в DIB-секцию виртуального экрана (все мониторы сразу).
* **Затемнение — два GDI-вызова** на кадр (`PatBlt` + `AlphaBlend`), без попиксельных циклов.
* **Оверлей — обычное окно с частичной перерисовкой.** Layered-окно пришлось бы толкать в композитор целиком (18 МБ на каждое движение мыши); здесь перерисовывается только изменившийся прямоугольник, поэтому рамка тянется плавно даже на старом железе.
* **Редактор — то же окно, что и выделение.** Никакого второго процесса/окна: пиксели кропаются из замороженного кадра и рисуются 1:1 поверх того места, откуда их взяли.
* **Память освобождается сразу.** Тяжёлые DIB-буферы (по 4 байта на пиксель виртуального экрана) живут только между PrintScreen и сохранением; в покое процесс держит ~15 МБ приватной памяти.

## Установка

1. Скачать `yas-shotter.exe` из [Releases](../../releases).
2. Положить в постоянную папку, например `%LOCALAPPDATA%\Programs\YASShoter\` (не в `Temp` — путь прописывается в автозапуск).
3. Запустить. Иконка появится в трее (Windows 11 по умолчанию прячет новые иконки в «переполнение» — YASShoter сам ставит себе `IsPromoted=1` в `NotifyIconSettings`, чтобы иконка была на панели задач).
4. Автозапуск включается сам (`HKCU\...\CurrentVersion\Run`), отключается в меню трея.

Меню трея: `Захват области` (`Ctrl+Alt+S` — резервная комбинация), `Открыть папку сохранения`, `Настройки (config.json)`, `Автозапуск`, `Выход`.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `PrintScreen` | захват (настраивается в конфиге) |
| `Ctrl+Alt+S` | резервный захват |
| `1`…`5` | инструмент: стрелка, рамка, эллипс, карандаш, метка |
| `+` / `-` | толщина линии |
| `Enter`, `Ctrl+S` | сохранить |
| `Ctrl+C` | скопировать |
| `Ctrl+Z`, `Backspace` | отменить последнюю аннотацию |
| `Esc`, `ПКМ` | отмена |

## Конфиг

`%APPDATA%\YASShoter\config.json`

```json
{
  "saveDir": "D:\\Downloads",
  "fileNameTemplate": "YAS_{date}_{time}",
  "color": "FF3B30",
  "thickness": 4,
  "hotkey": "PrintScreen",
  "autoStart": true,
  "copyToClipboard": true,
  "disableSnippingToolPrintScreen": false,
  "dimAlpha": 140,
  "trayPromoted": true
}
```

* `fileNameTemplate` — шаблон имени: `{date}`, `{time}`, `{datetime}`, `{yyyy}`, `{MM}`, `{dd}`, `{HH}`, `{mm}`, `{ss}`, `{unix}`.
* `hotkey` — `PrintScreen`, `Ctrl+Alt+S`, `Ctrl+Shift+4` и т. п.
* `dimAlpha` — сила затемнения фона (60…220).
* `disableSnippingToolPrintScreen` — дополнительно выключить системный перехват PrintScreen в реестре (по умолчанию не трогаем настройки системы: хук и так забирает клавишу первым).

Лог диагностики: `%APPDATA%\YASShoter\log.txt` (перезаписывается при старте, содержит только события и тайминги).

## Сборка

Нужен Go 1.22+ и — для иконки/манифеста — `go-winres`:

```bash
go install github.com/tc-hib/go-winres@latest

make            # иконка + ресурсы + кросс-сборка windows/amd64
make test       # go vet + сборка под windows/amd64
```

Сборка проверена кросс-компиляцией из Linux/WSL (`GOOS=windows GOARCH=amd64`, `CGO_ENABLED=0`). Тяжёлых зависимостей нет: только стандартная библиотека + собственные биндинги Win32 в `internal/win`.

## Структура

```text
.
├── main.go          резидентный цикл, хоткей, трей, меню, сохранение
├── overlay.go       замороженный кадр, выделение области, подсветка окна
├── editor.go        редактор 1:1 на месте выделения, клавиатура/мышь
├── toolbar.go       плавающая панель инструментов (не забирает фокус)
├── annotate.go      модель аннотаций: стрелка, рамка, эллипс, карандаш, метка
├── appicon.go       иконка трея (ресурс exe или отрисовка в рантайме)
├── config.go        config.json, шаблоны имён, копирование в буфер
├── util.go          мелкие утилиты
├── internal/win/    биндинги Win32 без CGO
│   ├── api.go       ленивая загрузка user32/gdi32/shell32/dwmapi/...
│   ├── types.go     структуры и константы
│   ├── win.go       окна, сообщения, DPI, DWM, known folders
│   ├── dib.go       DIB-секции, BitBlt/AlphaBlend, текст
│   ├── raster.go    свой антиалиасинг: линии, рамки, эллипсы, полигоны
│   ├── keyhook.go   WH_KEYBOARD_LL (PrintScreen на Windows 11)
│   ├── enum.go      поиск окна под курсором в Z-порядке
│   └── system.go    трей, буфер обмена, реестр, иконки
├── tools/genicon/   генератор .ico (PNG-в-ICO, без внешних утилит)
└── .github/         CI: сборка и релиз
```

## Ограничения

* Только Windows (Win32 API, `windows/amd64`).
* Захват — freeze-frame: живое видео/анимация на снимке замирают в момент PrintScreen (так же ведёт себя ShareX).
* Нет загрузки в облако, эффектов (blur/pixelate), записи видео и истории — сознательно вне рамок.
* HDR/широкий охват цветов не корректируется (как и в большинстве простых скриншотеров).
